## Run locally
1. Install Node.js (LTS).
2. Extract the ZIP and open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build for deployment
Run `npm run build`. The build script invokes TypeScript and Vite through Node directly to avoid relying on executable permissions of the shell launchers. Upload the generated `dist` folder to Netlify, or connect the repository to Vercel/Netlify with:
- Build command: `npm run build`
- Publish directory: `dist`
